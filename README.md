# gotolibray

一个适合部署到 Vercel 的轻量版捡漏助手：Vercel 只做瞬时 API 转发，轮询逻辑跑在手机浏览器里。

## 功能

- 手机端深色控制面板，首页、配置、日志三页。
- 登录系统：服务端会话保护主站和抢座 API，管理员可创建、禁用用户并查看活动日志。
- 头发余额：开始捡漏消耗 1 根头发；用户每日签到随机获得 0.01 到 1 根头发；管理员可给用户发放头发。
- 公告系统：管理员可发布公告，用户在首页查看。
- 低风控捡漏：持续检查空位，发现候选后串行尝试预约。
- 候选抢座：每轮只尝试少量座位，避免遍历所有空位拖慢速度并触发风控。
- 串行提交：每轮固定只提交 1 个座位请求，尽量接近人工操作节奏。
- 失败冷却：失败座位短暂跳过，避免反复撞同一个假空位。
- 风控保护：检测到频繁、封禁、验证码、登录异常等提示时自动停止。
- Web Worker 定时器：前台和轻后台状态下比普通 `setTimeout` 更稳。
- 通过 `/api/proxy` 转发 GraphQL 请求，前端用 `X-Trace-Cookie` 传 Cookie，代理端再转成真实 `Cookie` 请求头。
- 可选 `/api/session`：粘贴我去图书馆授权链接，辅助换取 Cookie，服务器不保存。
- Wake Lock 屏幕常亮、随机抖动、失败退避、日志和 ntfy.sh 通知。

## 部署到 Vercel

1. 将本目录推送到 GitHub 仓库。
2. 在 Vercel 新建项目并导入仓库。
3. Framework Preset 选择 `Other`，保持默认即可。
4. 部署完成后，用手机浏览器打开 Vercel URL。
5. 到“配置”页登录、选择阅览室并保存。

可选环境变量：

- `ALLOWED_ORIGINS`：限制允许访问 API 的前端来源，例如 `https://your-app.vercel.app`。不填默认 `*`。
- `ADMIN_USERNAME` / `ADMIN_PASSWORD`：首次启动时自动创建管理员账号。`ADMIN_PASSWORD` 至少 8 位。
- `AUTH_SECRET`：认证加盐密钥，生产环境务必设置为足够长的随机字符串。
- `AUTH_DATA_DIR`：用户、会话和活动日志保存目录，默认 `.data`。
- `AUTH_SESSION_DAYS`：登录有效天数，默认 7。

## 登录和用户管理

Azure/self-host 部署使用 `server.js` 提供完整登录系统。首次部署前建议在服务器服务环境里设置：

```bash
ADMIN_USERNAME=admin
ADMIN_PASSWORD=change-this-password
AUTH_SECRET=replace-with-a-long-random-secret
```

启动后访问 `/login.html` 登录，普通用户可从 `/register.html` 直接注册并使用。管理员进入 `/admin.html` 可发放头发、发布公告、禁用用户、修改角色、重置密码和查看简单活动日志。用户数据默认保存在 `.data/auth-store.json`，不要提交到 Git。

## 登录和阅览室获取

本项目参考 igolib 的思路，默认不需要手动抓包：

1. 打开部署后的页面，进入“配置”。
2. 点“复制登录链接”后发到微信里打开。
3. 微信授权后，复制跳转后的完整链接。链接里通常会包含 `code=...`。
4. 粘贴到“微信回调链接”，点“解析登录并获取阅览室”。
5. 页面会从回调链接提取 `code`，请求 `urlNew/auth.html` 换取 Cookie，然后自动调用 `libs(libType: -1)` 读取阅览室列表。
6. 在“阅览室”下拉框里选择目标阅览室并保存。

如果自动登录失败，再使用浏览器开发者工具或抓包工具复制请求里的 Cookie，手动填入：

```text
wechatSESS_ID=xxx; SERVERID=xxx
```

注意：浏览器不允许前端 JS 直接设置 `Cookie` 请求头，所以本项目使用 `X-Trace-Cookie` 发给自己的 Vercel 代理，再由代理请求上游。

## 使用建议

- 抢座前让手机页面保持前台打开，Wake Lock 只能在可见页面上尽量保持屏幕常亮，不能保证锁屏或后台继续执行。
- 默认捡漏间隔是 1.5 秒，每轮提交 1 个座位，每轮候选 1 个，失败冷却 8 秒。旧版浏览器缓存会被自动拉回这些低风控范围；如日志稳定，可手动调到 1 秒，不建议继续压低。
- 如果日志里经常出现“座位没人但失败”，通常是座位状态延迟、他人同时抢占、接口判定为假空位、账号限制或触发风控；不要继续提高频率。
- 如果你有偏好的座位号，在“偏好座位”里填 `101,102,103`，系统会优先尝试这些座位；不填则随机挑选空位，避免每轮固定撞同一个座位。
- 如果接口返回验证码错误，需要在配置里填写验证码字段，或改造为人工确认流程。
- 成功后页面会弹窗、播放提示音，并可向 ntfy.sh 推送。

## 本地预览

静态页面可以直接打开 `public/index.html`。如果要测试 API，请使用 Vercel 本地环境：

```bash
npx vercel dev
```

然后访问 `http://localhost:3000`。
